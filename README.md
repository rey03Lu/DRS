## Requisitos

- .NET SDK 8.0 o superior

## Compilar y ejecutar

### Opción sencilla: menú de ejercicios

Desde la raíz del proyecto:

```bash
cd MenuDeEjercicios
dotnet run
```

Elegís el número del ejercicio que quieras probar (1-5) y el menú lo abre por vos. Para salir, opción 0.

### Ejecutar un ejercicio en específico

NOTA: moverse a la carpeta del ejercicio específico

```bash
dotnet run
```

## Ejercicios incluidos

1. **Abstracción de Datos**: CuentaBancaria (depositar, retirar, consultar saldo).
2. **Encapsulación y Control de Acceso**: Empleado con propiedades validadas.
3. **Herencia Simple**: Vehiculo → Coche.
4. **Polimorfismo**: Animal → Perro / Gato con método sobrescrito.
5. **Herencia Multinivel**: Animal → Mamifero → Perro con sobrescritura.
